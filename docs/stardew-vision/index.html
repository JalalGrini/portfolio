The build order

Composition before decoration.

  1. Lock the palette, scale, room construction and dialogue language.
  2. Build an excellent connected home and research interior.
  3. Complete a physical two-stop tour through both rooms, including narration and exits.
  4. Author the full 21-place village and all project-specific spaces.
  5. Validate the full interior tour, mobile UI, accessibility and performance.
  6. Only then add seasonal dressing and optional flourishes.
